# 🤖 PM / PgM First 90 Days AI Assistant

An interactive, self-contained AI tool designed to help new Project and Program Managers succeed in their **first 90 days** on the job.

It provides intelligent guidance, ready-to-use outputs, and structured support for common challenges faced by new TPMs and PMs.

---

## ✨ Features

- Interactive AI assistant tailored for the critical first 90 days
- Covers stakeholder management, risk identification, executive communication, building credibility, early wins, and more
- Fully client-side (works offline after loading)
- Clean, professional interface with dark/light mode
- One-click copy for all outputs
- Ready for local use or easy deployment (Vercel/Netlify)

---

## 🚀 How to Use

1. Open **`ai_readiness_audit_v4.html`** in your browser
2. Select a scenario or topic relevant to your first 90 days
3. Get tailored, professional outputs instantly

**[→ Launch the AI Assistant](ai_readiness_audit_v4.html)**
