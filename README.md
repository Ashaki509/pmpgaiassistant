# 🤖 PM / PgM First 90 Days AI Assistant

A beautiful, self-contained AI-powered assistant with **10 proven prompts** to help new Project and Program Managers hit the ground running.

---

## ✨ Features

- 10 carefully designed prompts covering stakeholder management, risk analysis, executive communication, early wins, and more
- Fully client-side (no backend required)
- Clean, professional UI with dark/light mode support
- One-click copy for all generated outputs
- Ready for local use or easy deployment

---

## 🚀 Quick Start

1. Download or clone the repo
2. Open **`ai_readiness_audit_v4.html`** in your browser
3. Start using the prompts immediately

---

## 📁 Project Structure

- **`ai_readiness_audit_v4.html`** — Main single-file application
- **`api.js`** — API configuration (for Claude or other models)
- **`DEPLOYMENT_GUIDE.md`** — Deployment instructions
- **`docs/usage.md`** — Detailed usage guide
