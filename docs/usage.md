# Usage Guide - PM/PgM First 90 Days AI Assistant

## How to Use

1. Open the HTML file in any modern browser
2. Choose one of the 10 prompt cards on the left
3. Fill in the relevant context fields
4. Click **Generate**
5. Copy the output and use it directly

## Prompt Categories

**Analysis & Discovery**

## Tips for Best Results

- Be as specific as possible in the input fields
- Use real project context
- Combine outputs from multiple prompts
